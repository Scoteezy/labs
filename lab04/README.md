# Учебный набор постеров для ЛР 4

Архив содержит воспроизводимый демонстрационный набор из 36 SVG-постеров и
сопутствующие реестры для лабораторной работы 4. Это официальная учебная
демонстрация курса, запущенная локально из `demo/project.py`.

## Происхождение

Исходный репозиторий: https://github.com/Irina-64/ml-creative-technologies-course

Зафиксированный коммит: `844a315d71ffc11b8462308e158c24fb16253023`.
Локальный запуск выполнен 23.11.2026. Код курса распространяется по лицензии
MIT, её текст включён в `LICENSE`. SVG и записи созданы кодом генератора,
синтетические, без сетевых изображений и без персональных данных. Статус
`demo_allowed` является техническим статусом учебного примера и не заменяет
проверку прав при добавлении реальных материалов.

## Состав

`demo/data/raw.json` содержит 42 записи. Шесть контрольных записей не входят
в рабочий набор: `D001`--`D003` повторяют изображения, `X001` и `X002` имеют
неизвестный статус прав, у `X003` пустое описание. После очистки в
`demo/data/clean.json` остаётся 36 уникальных SVG.

У каждой карточки есть идентификатор, жанр, стиль, описание, автор и серия,
split, источник, статус прав, флаг `synthetic`, размеры, число кругов
(`objects`), путь к SVG и SHA-256.
Единица анализа — один учебный макет. В наборе шесть жанров по шесть макетов,
два стиля по 18 макетов и две ориентации 600x800 и 800x600 по 18 макетов.

## Воспроизведение

Требуется Python 3.10+ без сторонних библиотек.

```sh
python3 demo/project.py run
python3 demo/audit.py
```

Первая команда заново создаёт SVG, raw/clean-манифесты, запросы, результаты
очистки и файлы оценки. Вторая команда проверяет количество записей,
уникальность хешей, отсутствие записей с неизвестными правами и пустыми
описаниями в clean, размеры и целостность SVG по SHA-256, а также
разделение авторов и серий между train, validation и test. Итоги находятся
в `demo/results/reproducibility_audit.csv` и `.json`. Попарное
сравнение выборок сохранено в `demo/results/split_overlap.csv`.

## Разделение и ограничения

В каждом split 12 карточек. Train использует A01--A02 и S01--S02, validation
использует A03--A04 и S03--S04, test использует A05--A06 и S05--S06. IDF
рассчитывается только по train. Все описания русскоязычны и имеют одинаковую
структуру. В каждой паре выборок совпадают 12 описаний, 12 текстов запросов
и 12 шаблонов SVG после замены ID в подписи. Набор демонстрирует очистку и
контроль пересечений авторов, серий и файлов. Качество поиска на реальных
коллекциях и пользовательская полезность требуют отдельной проверки.
