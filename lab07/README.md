# Лабораторная работа 7. Baseline для проверки искажений упаковки

Baseline сравнивает исходную и рекламную версии одной области товара после подготовки из ЛР 6. Вход представляет пару RGB-изображений и две прямоугольные области товара. `lab06.prepare.prepare_pair` обрезает области, приводит их к 128×128, переводит в градации серого и возвращает массивы `float32` в диапазоне от 0 до 1.

Мера различия равна `1 - SSIM`. Больший score означает более сильное изменение. Порог для класса `critical_change` подбирается только на validation по максимуму F1, затем по Recall, Specificity и меньшему порогу при равенстве. Test не участвует в выборе порога.

```sh
python -m lab06.prepare --check
python -m lab07.baseline run
python -m lab07.baseline check
```

`results/scores.csv` содержит все оценки пар, [examples.csv](results/examples.csv) — примеры на validation, а `results/summary.json` — выбранный порог, F1, Precision, Recall, Specificity и матрицы ошибок по каждому split. Повторная команда `check` пересчитывает результаты и сверяет их с сохранёнными файлами.

Baseline чувствителен к изменениям освещения внутри области товара. Примеры ошибок и ограничения разобраны в [наблюдениях](findings.md) и [ЛР 8](../lab08). Набор является воспроизводимым синтетическим пилотом, результаты не характеризуют реальную рекламу после генеративного редактирования.
