# Лабораторная работа 7. Baseline для поиска референсов

Цель — зафиксировать воспроизводимую точку отсчёта для поиска по коллекции афиш. Baseline ранжирует карточки по косинусному сходству TF-IDF-векторов запроса и описания. Совпавшие слова позволяют объяснить позицию каждой карточки. Модель использует текстовые веса, подготовленные на train в ЛР 6.

## Запуск

Нужен Python 3.9+ со стандартной библиотекой. Команды выполняются из корня репозитория, поскольку фиксированный набор 2.0 находится в [lab06/data](../lab06/data).

```sh
python3 -m lab07.baseline check
python3 -m lab07.baseline run --out lab07-reproduction
```

Первая команда заново рассчитывает три отчёта и проверяет их побайтовое совпадение с опубликованными. Вторая сохраняет новые отчёты и сведения о текущем окружении в `lab07-reproduction/`. Команда `python3 -m lab07.baseline run` обновляет отчёты в `lab07/results/`.

Для ручной проверки используются те же карточки validation. Поисковая команда выводит ID и оценки сходства для произвольного запроса.

```sh
python3 -m lab07.baseline search --query "выставка минимализм с чистой композицией"
python3 -m lab07.baseline search --query "джаз минимализм в ясной концертной графике"
```

Первый запрос возвращает `P022` и `P033`. Второй даёт пустой список.
