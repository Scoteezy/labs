# Фиксированные настройки baseline

| Параметр | Значение |
|---|---|
| Набор | 2.0 из ЛР 6, 36 карточек и 36 запросов |
| Обучение IDF | 12 описаний train, 87 токенов в словаре |
| Оценка | 12 запросов и 12 допущенных карточек validation, 144 оценки пар |
| Глубина выдачи | `k = 3` |
| Вход ранжирования | Текст запроса и поле `description` карточки |
| Токенизация | Unicode NFKC, `casefold`, последовательности по шаблону `[a-zа-яё0-9]+` |
| Вес токена | Счётчик вхождений × IDF из ЛР 6, затем L2-нормализация |
| Неизвестные токены | Пропуск. Пустой запрос или нулевой вектор даёт пустую выдачу |
| Сортировка | Положительное сходство по убыванию, при равенстве ID по возрастанию |
| Точность | Веса IDF, компоненты векторов и сходство округляются до 12 знаков |
| Случайность | Отсутствует. Seed не применяется |
| Окружение | Python 3.9+ и стандартная библиотека. Опубликованный расчёт выполнен на CPython 3.9.6 |
| Команда из корня | `python3 -m lab07.baseline run` |

Использованы зафиксированные файлы `clean.json`, `split.json`, `queries.json`, `qrels.csv` и `idf.json`. Их контрольные суммы сверяются перед расчётом. SHA-256 файла настроек записывается в подробный отчёт. Происхождение данных и веса IDF описаны в [ЛР 6](../lab06/README.md). Контрольные суммы приведены в [конфигурации](settings.json) и [манифесте набора](../lab06/data/manifest.json).

`IDF(t) = 1 + ln((1 + N) / (1 + df(t)))`. Здесь `N = 12`, а `df(t)` — число описаний train, содержащих токен `t`. Вектора описаний и запросов validation строятся с этими весами. Жанр и стиль используются в готовых оценках `qrels.csv`. При вычислении сходства учитываются только текстовые векторы. ID нужен для стабильной сортировки. Test зарезервирован для последующей оценки.

## Соглашения по метрикам

- **NDCG@3** — отношение DCG выдачи к идеальному DCG для этого запроса. На позиции `i`, начиная с 1, вклад равен `(2^grade − 1) / log2(i + 1)`. Идеальная выдача получается сортировкой оценок всех 12 карточек по убыванию.
- **Recall@3** — число карточек с оценкой выше нуля в top-3, делённое на число таких карточек среди всех кандидатов. В этой выборке у каждого запроса две релевантные карточки, с оценками 2 и 1.
- Пустая выдача даёт 0 по обеим метрикам. Средние рассчитаны по запросам с одинаковым весом, включая пустые ответы.
