# Лабораторная работа 5. Разведочный анализ пар изображений

Проект проверяет искажения косметической упаковки в рекламных изображениях после генерации.
ЛР 5 исследует пары ЛР 4 до подготовки входов модели.

## Запуск

    python -m pip install -r lab04/requirements.txt
    python -m lab04.generate
    python -m lab05.analysis

Скрипт создаёт шесть PNG в lab05/results/figures, таблицу quality_checks.csv и обновляет
quality_review.md с решениями по данным.

## Вопросы

1. Есть ли оба класса в train, validation и test?
2. Какие контролируемые изменения представлены?
3. Не совпадает ли вариация сцены с меткой?
4. Не выдаёт ли размер области товара метку?
5. Изолированы ли семьи товаров между split?
6. Валидны ли PNG, области товара и идентификаторы?
7. Можно ли визуально проверить штатную пару и три класса дефектов?

Пилот создан процедурно и проверяет воспроизводимость конвейера. Он не подтверждает качество
на реальных результатах генеративного редактирования.
