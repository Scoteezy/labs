# Лабораторная работа 10. Выбор архитектуры и инструментов

Проект «Поиск референсов в коллекции афиш». Для учебной alpha выбран локальный TF-IDF с общим фильтром допуска. Baseline служит штатным и резервным режимом. Жанровая нормализация доступна в контролируемом прогоне. Она подняла NDCG@3 на validation с 0,238525 до 0,857373, а на отложенном test получила 0,355740 при ориентире 0,70.

## Воспроизведение

Из корня репозитория, Python 3.9+ со стандартной библиотекой.

```sh
python3 -m lab09.experiment check
python3 -m lab10.measure
```

Первая команда сверяет девять пересчитанных файлов LR09-E01. Вторая проверяет выдачи и повторяет замер поискового ядра. Время зависит от машины и нагрузки. Чтобы сохранить результат нового замера, добавьте `--out lab10-reproduction/latency.json`. Контракты HTTP и событий в схеме относятся к проектированию alpha для следующей лабораторной.
