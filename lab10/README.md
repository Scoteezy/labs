# Лабораторная работа 10. Архитектура проверки упаковки

Проект проверяет пару изображений косметической упаковки после рекламного редактирования. Alpha получает два PNG и две области товара, приводит области к одному размеру и возвращает предупреждение о предполагаемом критическом изменении. Дизайнер сравнивает изображения и принимает решение.

Архитектурный вопрос: какой локальный способ оценки использовать в первой alpha-версии, если данные ограничены контролируемым синтетическим пилотом, а выбор остаётся за дизайнером.

## Воспроизведение

Команды запускаются из корня репозитория после установки зависимостей ЛР 4.

    python -m lab04.generate --check
    python -m lab06.prepare --check
    python -m lab07.baseline check
    python -m lab09.experiment check
    python -m lab10.measure

Последняя команда сначала сверяет решение ЛР 9, затем измеряет только подготовку пары из файлов и выбранную оценку. Чтение JSON, запуск процесса и HTTP в измерение не входят. Значения зависят от машины и нагрузки.

## Границы alpha

Компонент работает с одним товаром в близком фронтальном ракурсе и с явно заданными прямоугольными областями товара. Учебный набор создан процедурно и содержит контролируемые изменения. Результаты не характеризуют надёжность на реальных генеративных изображениях, сильных поворотах, перекрытиях или нечитабельных этикетках.
