## Решение и основания

Выбрана единая архитектура локального TF-IDF-поиска с общим контролем допуска, источником в каждом результате и выбором референса дизайнером. В штатном режиме работает baseline. Учебная настройка включает нормализацию по словарю 1.0 с собственным train-IDF. При сбое этого режима используется исходный запрос и независимый базовый IDF. Дизайнер получает явный статус и может открыть карточки проверенного каталога. [Схема и ответы при отказе](architecture.md)

На validation кандидат поднял NDCG@3 на 0,618849 и Recall@3 с 0,208333 до 0,875000. На отложенном test NDCG@3 кандидата составила 0,355740 при ориентире 0,70. На V19 нормализация подняла менее подходящий по стилю референс на первое место. Эффект переноса словаря остаётся самым рискованным допущением. Baseline также ниже ориентира. Он выбран для штатного учебного запуска из-за простоты диагностики и воспроизводимости. [Эксперимент LR09-E01](../lab09/decision.md) · [Сравнение альтернатив](architecture_matrix.md)

Готовый локальный энкодер остаётся альтернативой для будущего прогона. Переход потребует замера на том же сценарии, оценки потребления ресурсов и проверки лицензий. Ранжирование и просмотр SVG возможны на CPU без внешней модели, API-ключей, сетевых запросов и GPU. Прямые расходы на API равны нулю. Полная стоимость владения не измерена.

## Допущения и пересмотр

- Каталог малый и учебный. Запросы короткие, русскоязычные и относятся к поиску по описаниям. Качество для естественных брифов требует замера.
- Для alpha остаются обязательными источник, проверка допуска, ручное решение и понятный резервный режим. Архивариус проверяет права на реальные материалы и изменения каталога. Разработчик восстанавливает компоненты по манифесту. Дизайнер проверяет востребованность карточек и подаёт исправления.
- На новой версии данных нужны естественные брифы и независимые оценки по жанру и стилю. До прогона фиксируются разбиение, qrels, версии и пороги. На отдельной отложенной группе сравниваются оба режима. Для кандидата требуется NDCG@3 не ниже 0,70 и Recall@3 не ниже baseline. Для обоих режимов требуется ноль недопущенных карточек. Пустые выдачи и снижение стилевой релевантности разбираются отдельно. Время ответа до 10 секунд проверяется по полному пути запроса. Цель выбора референса за пять минут проверяется с дизайнером отдельным наблюдением.
- При расширении архива, появлении многоязычных брифов, поиске по самому изображению или превышении целевой задержки пересматривается архитектура. Для следующего сравнения сохраняются общий сценарий, ограничения допуска и отчёт о том, какой ресурс изменился.
