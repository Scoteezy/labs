# ADR-01. Локальная оценка SSIM для alpha

| Поле | Значение |
|---|---|
| Статус | Принято для учебной alpha |
| Дата | 24.11.2026 |
| Решение | Использовать 1 - SSIM на подготовленных областях товара и порог 0,017705861976 |
| Основание выбора | F1 на validation 0,872727. Candidate дал F1 0,738462 и не выполнил условие включения |
| Данные | Набор 1.0, 192 контролируемые синтетические пары, split по 12 семействам |

## Роли средств

| Средство | Роль |
|---|---|
| Python 3.12 | Локальный запуск и JSON |
| Pillow 11.3.0 | Декодирование PNG, crop и масштабирование |
| NumPy 2.2.6 | Представление подготовленных массивов |
| scikit-image 0.25.2 | Расчёт SSIM |
| http.server | Учебный localhost API в ЛР 11 |

Внешние API, ключи, GPU и платные вызовы не используются. Все исходные изображения набора генерируются скриптом ЛР 4 и имеют статус project_generated.

## Отказ и пересмотр

Если загруженные решение или функции SSIM недоступны, сервис возвращает 503 model_unavailable и не создаёт оценку. Экспериментальный candidate при сбое переключается на baseline. Штатная конфигурация выбирает baseline напрямую.

Решение пересматривается, если появятся реальные результаты генеративного редактирования, сильные ракурсы, разные типы упаковки, потребность в автоматической локализации области товара или новая модель с измерением на зафиксированном разбиении. Тогда требуется новый эксперимент без использования test для выбора настроек.
