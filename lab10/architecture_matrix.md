# Матрица выбора архитектуры

Общий сценарий — два кадра одного товара с размеченными областями. В автоматических режимах используется локальный CPU, алгоритм возвращает объяснимый статус, итоговое решение принимает дизайнер. Шкала от 1 до 3 одинакова для всех строк: 1 означает существенное ограничение, 2 — приемлемый компромисс, 3 — лучшее соответствие условиям пилота.

| Критерий | A. Ручное сравнение | B. Глобальный SSIM | C. SSIM + q90 разности |
|---|---|---|---|
| Качество сигнала | 2 · зависит от опыта, не измерялось | 3 · F1 0,872727, Recall 1,000 | 2 · F1 0,738462, Recall 1,000 |
| Требования к данным | 3 · нужны две картинки одного товара | 3 · те же картинки и сопоставимые области | 3 · та же предобработка и данные для порога |
| Задержка | 1 · время дизайнера предстоит измерить | 3 · локальный замер на validation | 3 · локальный расчёт, тот же набор операций плюс квантиль |
| Прямые расходы API | 3 · внешних вызовов нет | 3 · внешних вызовов нет | 3 · внешних вызовов нет |
| Лицензии | 3 · допущенные изображения | 3 · те же изображения, локальные библиотеки | 3 · те же зависимости |
| Объяснимость | 3 · дизайнер может указать конкретное изменение | 2 · видно порог и силу сигнала | 2 · видно силу составного сигнала |
| Поддержка | 2 · необходима инструкция проверки | 3 · одно вычисление и порог | 2 · фиксируются вес и квантиль |
| Риск влияния света | 2 · трудные блики требуют проверки | 2 · 7 ложных тревог на validation | 1 · 17 ложных тревог на validation |
| **Сумма** | **19** | **22** | **19** |

Баллы ручного способа предварительные. Для метрик использован [эксперимент ЛР 9](../lab09/results/summary.json). Задержка [измерена для штатного устройства и baseline](results/latency.json). Оценка задержки C инженерная и означает, что кандидат использует то же локальное вычисление без внешних вызовов. Стоимость ручной работы, поддержка и системное время реакции отдельно не замерялись.

SSIM выбран по валидационным результатам. Ручное сравнение завершает пользовательский сценарий и служит резервом при несопоставимой паре. Предобученные признаки или OCR потребуют новой проверки качества, происхождения весов, лицензии и локальной задержки.
