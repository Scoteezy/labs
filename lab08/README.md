# Лабораторная работа 8 — Метрики и анализ ошибок

Проект «Поиск референсов в коллекции афиш». Цель — выбрать показатели полезности ранжирования и сформулировать эксперимент по результатам разбора ошибок. Расчёт использует набор 2.0 из [ЛР 6](../lab06) и фиксированный косинусный TF-IDF baseline из [ЛР 7](../lab07).

На 12 запросах validation **NDCG@3 = 0,238525**, **Recall@3 = 0,208333**. У буквальных запросов NDCG@3 равна 0,362294, у ассоциативных — 0,114755. Семь запросов остались без релевантной карточки, в том числе четыре с пустой выдачей. У театра обе метрики равны нулю на двух запросах. Среди 16 выданных позиций нет карточек с неизвестным допуском. Baseline ниже порога качества alpha 0,70.

Для ЛР 9 зафиксирована H1 о нормализации жанровых словоформ и ассоциаций в запросах и описаниях. Эксперимент будет проверяться на том же validation с пересчётом IDF по train.

## Воспроизведение

Из корня репозитория, Python 3.9+ со стандартной библиотекой.

```sh
python3 -m lab07.baseline check
python3 -m lab08.analysis check
```

Сохранить пересчитанные таблицы в отдельную папку можно командой `python3 -m lab08.analysis run --out lab08-reproduction`. [Код анализа](analysis.py) загружает входы через baseline ЛР 7 с проверкой SHA-256, повторно строит неизменённую выдачу и формирует срезы. Контроль допуска использует временную копию набора. Test зарезервирован для последующей оценки.
