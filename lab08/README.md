# Лабораторная работа 8. Метрики и ошибки

ЛР 8 анализирует SSIM baseline из ЛР 7 для проекта проверки искажений косметической упаковки. Основная метрика — F1 класса `critical_change`. Precision показывает долю обоснованных тревог, Recall — долю обнаруженных критичных изменений, Specificity — долю корректно пропущенных допустимых изменений. Порог принадлежит ЛР 7 и выбран только на validation.

```sh
python -m lab07.baseline check
python -m lab08.analysis run
python -m lab08.analysis check
```

`results/analysis.json` содержит показатели по типам дефекта и вариациям, ошибки validation и гипотезу ЛР 9. Контролируемое изменение в ЛР 9 добавляет локальный сигнал различий в тот же процесс подготовки изображений. Test не используется для выбора гипотезы.

Ограничение. Набор состоит из синтетически сформированных пар с контролируемыми изменениями. Ошибки и метрики характеризуют этот пилот, а не надёжность проверки изображений от внешних генеративных моделей.
