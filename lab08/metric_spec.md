# Спецификация метрик поиска референсов

## Единица оценки и шкала

Одна единица — один текстовый запрос. Используются 12 фиксированных запросов validation и 12 допущенных карточек этого разбиения, всего 144 пары с оценками. В выдаче до трёх карточек, `k = 3`. Среднее вычисляется по запросам с одинаковым весом. Для выводов приводятся размер сегмента и число отказов. [Данные и разбиение](../lab06/README.md) · [Настройки baseline](../lab07/settings.md)

| Балл | Правило |
|---:|---|
| 2 | Совпадает жанр и целевой стиль «минимализм» |
| 1 | Совпадает жанр, стиль отличается |
| 0 | Жанр отличается |

В validation каждому запросу соответствуют ровно две релевантные карточки, по одной с уровнями 2 и 1. Жанр и стиль используются для оценки qrels. Ранжировщик использует текст запроса и описания карточек.

## Метрики и условия приёмки

| Показатель | Расчёт и назначение | Порог alpha | Baseline |
|---|---|---|---:|
| Средняя NDCG@3 | Оценивает полезность и порядок первых трёх позиций. Карточка с баллом 2 в начале даёт больший вклад | ≥ 0,70 | 0,238525 |
| Средний Recall@3 | Доля найденных карточек с баллом выше нуля. Защищает полноту при улучшении порядка | ≥ baseline, то есть ≥ 5/24 | 0,208333 |
| Выдача без допуска | Число позиций, где статус отличается от `demo_allowed`. Нарушение блокирует выпуск | 0, в том числе в контрольном сценарии | 0 из 16 |
| Диагностика | Доля пустых выдач, доля запросов без релевантного попадания и доля запросов с баллом 2 на первой позиции | Сравниваются по типу и жанру | 4/12, 7/12 и 2/12 |

Технический порог 0,70 взят из спецификации курса. Три места соответствуют короткому списку кандидатов по R1. Градуированная NDCG различает точное и частичное соответствие и учитывает позиции нескольких полезных карточек. Recall@3 показывает, сохранилась ли возможность выбора, когда первый результат стал лучше. Проверка допуска R3 имеет отдельный порог, поскольку высокая релевантность не компенсирует неизвестное происхождение материала. [Требования ЛР 3](https://github.com/Irina-64/ml-creative-technologies-course/tree/main/labs/03)

## Формулы и крайние случаи

- `DCG@3 = Σ (2^relᵢ − 1) / log₂(i + 1)` для выданных позиций `i = 1…3`. Вклад отсутствующих позиций равен нулю.
- `IDCG@3` считается по трём наибольшим оценкам из всех допущенных кандидатов запроса. `NDCG@3 = DCG@3 / IDCG@3`.
- `Recall@3 = число выданных карточек с rel > 0 / число допущенных карточек с rel > 0`.
- Если релевантные кандидаты есть, а выдача пустая, обе метрики равны нулю. Запрос остаётся в среднем.
- Если релевантных кандидатов нет, техническая функция ЛР 7 возвращает два нуля. В будущей выборке такие запросы исключаются из средних NDCG и Recall с явным указанием знаменателя. Их считают отдельно по доле корректных пустых ответов среди запросов без релевантных кандидатов. Проверка допуска охватывает любую выдачу.

Цель «обоснованный выбор первого референса за пять минут» проверяется в отдельном пользовательском сценарии. Владелец проверки — дизайнер вместе с исследователем.
