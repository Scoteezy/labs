# Спецификация метрик

Положительный класс — `label=1`, критичное изменение упаковки. Предсказание положительно, если score не меньше порога, выбранного в ЛР 7 на validation.

- Precision = TP / (TP + FP). Показывает, как часто тревога соответствует контролируемому критичному изменению.
- Recall = TP / (TP + FN). Это защитная метрика, потому что пропуск изменения требует ручной проверки дизайнером.
- F1 — гармоническое среднее Precision и Recall. Это основная метрика выбора порога и сравнения ЛР 9.
- Specificity = TN / (TN + FP). Она показывает устойчивость к допустимым изменениям фона и освещения.

Метрики приводятся отдельно по `train`, `validation` и `test`, а также по типу дефекта и вариации. Для сегмента с одним классом F1 или Recall могут быть нулевыми по определению. Это не означает нулевую полезность этого сегмента.

Решение о включении варианта принимается по порогу улучшения: прирост F1 на validation хотя бы на 0,02 и Recall на уровне baseline или выше.

Validation используется для выбора порога и решения ЛР 9. Test читается только после фиксации решения. Пилот содержит процедурно созданные пары и не служит оценкой реального потока рекламных изображений.
