# Решение по LR09-LOCAL-01

В alpha используется baseline SSIM с порогом из [decision.json](results/decision.json). На validation F1 снизился с 0,872727 до 0,738462 при одинаковом Recall 1,000. Кандидат дал 17 ложных тревог против 7 у baseline и не выполнил условие роста F1 на 0,02.

Само решение и оба порога фиксируются до расчёта по test. Общие показатели test и матрицы для каждого типа вариации доступны в [summary.json](results/summary.json). Вывод относится к фиксированной комбинации SSIM и 90-го квантиля разности на контролируемых парах версии 1.0. Следующий эксперимент с OCR или выравниванием требует отдельного протокола и данных с реальными генеративными результатами.
