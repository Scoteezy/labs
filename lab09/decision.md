# Решение по эксперименту LR09-E01

## Решение по validation

**Включить нормализацию жанров в учебную alpha проекта.** Оба режима сохранены. Решение принято по validation до запуска test.

| Условие | Получено на validation | Итог |
|---|---:|---|
| Абсолютный прирост NDCG@3 ≥ 0,10 | +0,618849 | Выполнено |
| Recall@3 ≥ baseline и ≥ 5/24 | 0,208333 → 0,875000 | Выполнено |
| Ноль выдач без допуска, контроль с `unknown` проходит | 0 из 31 позиции у кандидата. Контроль пройден в обоих режимах | Выполнено |
| NDCG@3 ≥ 0,70 для alpha | 0,857373 | Выполнено |

Все условия H1 выполнены. Подстановка жанровых токенов дала хотя бы одно релевантное попадание во всех 12 случаях. У V19 NDCG@3 снизилась с 0,826235 до 0,796708. Второй релевантный вариант попал в выдачу, а карточка с баллом 2 сместилась с первого места на второе. Нормализация улучшает жанровое совпадение, а порядок по стилю может ухудшаться. [Машиночитаемое решение](results/validation_decision.json) · [Проверки допуска](results/validation_checks.json)

Словарь опирается на диагностику validation, поэтому прирост на этой выборке относится к настройке в пределах проекта. После фиксации решения выбранный режим проверен на отложенных группах test. Синтетические запросы и оценки по правилам позволяют проверять ранжирование внутри коллекции. Для оценки поиска по естественным брифам нужны запросы дизайнеров с независимой разметкой, включая смешанные жанры, многозначные слова и формулировки на других языках. [Сравнение](comparison.md)

## Итог после test

**Проверить дополнительно перед включением как основного режима.** На отложенных 12 запросах кандидат дал NDCG@3 **0,355740** при ориентире 0,70 и Recall@3 **0,333333**. Допуск соблюдён во всех 27 позициях. Словарь и решение о выборе кандидата по validation сохранены. Оценка test показывает абсолютное качество выбранного режима в другой группе карточек. Сравнение с baseline выполнено на validation. [Итоги test](results/test_summary.json)

Оба режима доступны для учебной проверки. Для следующего эксперимента нужны естественные брифы и независимые оценки на новых карточках. Стоит проверить, может ли один механизм подстановки одновременно сохранять порядок по стилю и находить карточки с жанровыми формулировками за пределами словаря 1.0.
