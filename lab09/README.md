# Лабораторная работа 9. Контролируемый эксперимент

ЛР 9 проверяет одну гипотезу после анализа SSIM baseline. Candidate не меняет набор, split или подготовку фрагментов. К SSIM-разности добавлен 90-й квантиль абсолютных различий пикселей в той же области упаковки:

`0.55 × SSIM-разность + 0.45 × q90(abs(разность))`.

Порог для каждого метода выбирается только по validation как максимум F1. Candidate включается в alpha, если F1 вырос не менее чем на 0.02 и Recall не ниже baseline. Test вычисляется после фиксации этого правила. Выбор и оба порога сохранены в `results/decision.json`.

```sh
python -m lab07.baseline check
python -m lab08.analysis check
python -m lab09.experiment run
python -m lab09.experiment check
```

В `results/summary.json` находятся показатели обоих методов на train, validation и test. Результаты относятся к контролируемому синтетическому набору и не доказывают эффективность на реальных генеративных рекламных изображениях.
