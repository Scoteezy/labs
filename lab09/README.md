# Лабораторная работа 9. Эксперимент с улучшением

Эксперимент LR09-E01 продолжает проект «Поиск референсов в коллекции афиш». Сравнивается TF-IDF baseline из ЛР 7 с вариантом, который заменяет жанровые слова в запросах и описаниях по словарю, зафиксированному в ЛР 8.

На validation NDCG@3 выросла с **0,238525** до **0,857373**, Recall@3 — с **0,208333** до **0,875000**. На отложенном test выбранный вариант получил NDCG@3 **0,355740** и Recall@3 **0,333333**. Выдачи без допуска отсутствуют в обоих разбиениях. Решение после test — **проверить дополнительно перед включением как основного режима**.

## Воспроизведение

Нужен Python 3.9+ со стандартной библиотекой. Команды выполняются в корне репозитория. Для повторного запуска можно указать новую папку.

```sh
python3 -m lab09.experiment validation --out lab09-reproduction
python3 -m lab09.experiment test --out lab09-reproduction
python3 -m lab09.experiment check --out lab09-reproduction
python3 -m lab09.experiment check
```

`validation` сохраняет выдачи обоих режимов, метрики, проверки допуска и выбор режима для отложенной оценки. Команда `test` читает сохранённое решение из той же папки и проверяет хеши конфигурации, словаря и весов. `check` побайтово сверяет девять файлов расчёта. Сведения о текущем окружении сохраняются отдельно.
