# План эксперимента LR09-E01

**H1.** Приведение жанровых словоформ и ассоциаций к общим токенам в запросах и описаниях повысит среднюю NDCG@3 на validation минимум на **0,10** по абсолютной шкале. Recall@3 должна быть не ниже baseline и 5/24. В выдаче допускается **0** позиций без статуса `demo_allowed`. [Гипотеза ЛР 8](../lab08/hypothesis.md)

## Варианты

- Baseline использует исходные токены и [веса IDF ЛР 6](../lab06/data/idf.json).
- Кандидат применяет [словарь 1.0](lexicon.json) после общей токенизации. Каждое точное совпадение с формой заменяется на один канонический токен. Например, «саксофон» и «джазовая» превращаются в «джаз». Остальные токены и количество вхождений сохраняются. IDF пересчитывается по тем же 12 описаниям train с применённой заменой.

IDF кандидата меняется вслед за представлением текста. Формула и данные для её расчёта общие. Словарь целиком перенесён из ЛР 8, где его состав определили по train и диагностике validation. Его правила относятся к учебной коллекции афиш.

| Метрики | [Спецификация ЛР 8](../lab08/metric_spec.md). Средние NDCG@3 и Recall@3 по запросам. Дополнительно — пустые ответы, запросы без релевантных результатов и карточки с баллом 2 на первой позиции |
| Допуск | Перед ранжированием отбираются карточки со статусом `demo_allowed`. Проверяются все выдачи и сценарий с контрольной карточкой `unknown` |

## Правило решения

1. Пересчитать оба варианта на одних и тех же запросах validation. Сравнить средние, типы формулировок, жанры и исходы. Отдельно проверить V13, V16, V23, V17 и V19.
2. Считать H1 подтверждённой при выполнении всех трёх условий. Решение вычислять по значениям до округления. Для включения в учебную alpha дополнительно требуется NDCG@3 ≥ 0,70.
3. Зафиксировать выбор по validation. При подтверждении H1 измерить результат выбранного кандидата на отложенном test. Оценку test использовать для проверки переноса, сохраняя версию словаря, параметры и решение по validation.
4. Сохранить оба результата validation, включая ухудшения по отдельным запросам, хеши IDF, версию Python и команды запуска.
