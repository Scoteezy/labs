## Воспроизведение

Нужен Python 3.9 или новее со стандартной библиотекой. Скачайте весь репозиторий, поскольку входные реестры и SVG находятся в соседней папке `lab05/data`. Выполните команды из корня репозитория.

```sh
cd lab06
python3 prepare.py --check
python3 -m unittest -v
```

Первая команда пересобирает набор во временной папке и сравнивает контрольные суммы всех файлов с опубликованными. Вторая проверяет пограничные случаи, очистку, групповые пересечения и инвариантность IDF при подмене отложенных описаний.

Чтобы записать пересобранную копию в отдельную папку, выполните `python3 prepare.py --out /путь/к/новой/папке`. Первичные ответы пилота уже сохранены. Чистый лист для повторной разметки создаёт `python3 prepare.py --pilot-board pilot`. Откройте `pilot/index.html` в браузере и примените инструкцию к карточкам с кодами B01–B12.

## Порядок подготовки

1. Прочитать исходные карточки ЛР 5. Проверить допуск, заполненность описания и SHA-256 доступных SVG. Удалить повторы с сохранением исходной карточки.
2. По утверждённой политике отнести автора, серию и семейство шаблона к одному разбиению. Сформировать SVG 2.0, новые описания и тексты запросов с прежними ID.
3. Получить метки из сохранённых SVG. Для пилота сопоставить их с первичными визуальными ответами. При расхождении использовать документированное решение. Проверить состав разбиений и отсутствие пересечений.
4. Рассчитать оценки релевантности по жанру и итоговому стилю. Построить словарь и IDF по описаниям `train`. Применить фиксированные веса к описаниям и запросам всех выборок.

Для ЛР 7 используются `clean.json`, `split.json`, `queries.json` и `qrels.csv`. `idf.json` и `tfidf.json` содержат веса и векторы базового представления. Для поиска используйте текстовые векторы. Поля жанра и стиля нужны для расчёта релевантности, а идентификаторы и группы — для контроля разбиения.
