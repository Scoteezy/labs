# Контракт локального поиска афиш

## Запрос

`POST /search` принимает JSON в UTF-8 с `Content-Type: application/json` и одним корректным `Content-Length`. Обязательное поле объекта `query` имеет тип string. После удаления внешних пробельных символов длина составляет от 1 до 300 кодовых точек Unicode включительно. Предел размера всего тела составляет 4096 байт. Дополнительные поля игнорируются. Режим задаёт оператор при запуске.

```json
{"query":"афиша крупным акцентом"}
```

## Успешный HTTP-ответ

| Поле | Тип и смысл |
|---|---|
| `status` | string. `ok` при совпадениях в выбранном режиме, `fallback` при найденных совпадениях после переключения, `no_matches` при пустой выдаче |
| `mode` | string. Фактически использованный режим `baseline` или `candidate` |
| `fallback_reason` | string или null. `candidate_unavailable` при переключении на baseline, включая случай пустой выдачи |
| `model`, `model_version` | string. `tfidf` или `tfidf_genre_normalization` и версия модели `1.0` |
| `dataset_version` | string. Версия каталога `2.0` |
| `lexicon_version` | string или null. Версия `1.0` для candidate и null для baseline |
| `results` | array. От 0 до 3 карточек |
| `human_decision_required` | boolean. `true`, если есть карточки для выбора |

Карточка содержит строковые поля `id`, `genre`, `style`, `source`, `rights_status`, `image`, числовое поле `score` и массив строк `matched_terms`. Среди карточек с допуском `demo_allowed` и заполненным источником выдаются совпадения с положительным косинусным сходством. Они отсортированы по убыванию `score`, при равенстве — по `id`. Поле `matched_terms` перечисляет общие слова в векторах после обработки выбранным режимом. `score` измеряет сходство описания с брифом. Решения о выборе и использовании референса принимает человек.

`GET /posters/{id}` выдаёт SVG с `Content-Type: image/svg+xml` для допущенной карточки по адресу из `image`. Дополнительно сверяется SHA-256 содержимого. Список результатов и доступ к изображениям используют один каталог допуска.

## Ошибки

Ошибки обработчиков возвращают JSON с `status`, `error` и `results: []`. У 503 статус `unavailable`, у остальных ошибок статус `error`.

| HTTP | `error` | Условие |
|---|---|---|
| 400 | `invalid_json` | Тело запроса не удалось прочитать как JSON в UTF-8 |
| 400 | `invalid_content_length` | Нет единственного корректного `Content-Length` или задан `Transfer-Encoding` |
| 400 | `incomplete_body` | Не удалось прочитать указанное количество байт тела |
| 400 | `object_required` | На верхнем уровне JSON пришло значение другого типа |
| 400 | `query_must_be_string` | Поле отсутствует или его тип отличается от string |
| 400 | `empty_query` | После удаления внешних пробелов строка пуста |
| 400 | `query_too_long` | После удаления внешних пробелов длина превышает 300 символов |
| 404 | `not_found`, `poster_not_found` | Неизвестный маршрут или отсутствующий ID допущенной афиши |
| 413 | `body_too_large` | Тело запроса превышает 4096 байт |
| 415 | `unsupported_media_type` | Тип тела отличается от `application/json` |
| 503 | `catalog_unavailable` | Базовый индекс или данные допуска не прошли загрузку и проверку |
| 503 | `image_unavailable` | SVG не прошёл чтение или проверку хеша |

Оба режима используют каталог и метаданные [ЛР 6](../lab06/data_card.md) и веса, рассчитанные по 12 карточкам train. Параметры, версии и SHA-256 зафиксированы в [config.json](config.json). Компонент выполняет поиск по локальному каталогу. Генеративная модель, контекст для LLM и шаблон промпта отсутствуют. [Фактические ответы](results/api_examples.json)
