# Лабораторная работа 11. Минимальный модуль поиска референсов

Локальный HTTP-компонент для дизайнера продолжает проект «Поиск референсов в коллекции афиш». Он принимает короткий текстовый бриф, возвращает до трёх карточек с источниками и показывает, какие термины совпали. Поиск идёт по 36 синтетическим афишам из [собственного каталога ЛР 6](../lab06). Окончательный выбор делает дизайнер.

В штатном режиме работает TF-IDF из [ЛР 7](../lab07). Учебный режим использует жанровые замены и отдельные train-IDF из [ЛР 9](../lab09). При недоступности словаря или его весов модуль переключается на штатный режим, как предусмотрено [решением ЛР 10](../lab10/architecture_decision.md). Сервис при старте сверяет SHA-256 и версии входов. Для выдачи учитываются допуск и источник, для просмотра SVG дополнительно проверяется хеш изображения.

## Запуск

Выполняйте команды из корня репозитория с Python **3.9+**. Нужна только стандартная библиотека. На свежем клоне сохраните исходные окончания строк для проверки хешей, например `git -c core.autocrlf=false clone https://github.com/Scoteezy/labs.git`.

```sh
python3 -m lab11.server
```

В другом терминале отправьте запрос. Штатный ответ имеет HTTP 200, статус `ok` и карточки `P001`, `P011`, `P027` в этом порядке.

```sh
curl -sS http://127.0.0.1:8765/search \
  -H 'Content-Type: application/json; charset=utf-8' \
  --data-binary '{"query":"афиша крупным акцентом"}'
```

Изображение первой карточки открывается по адресу <http://127.0.0.1:8765/posters/P001>. Остановите сервер через Ctrl+C. Для режима со словарём запустите `python3 -m lab11.server --mode candidate` и отправьте `{"query":"саксофон"}`. Он вернёт `P006`, `P005`, `P004`. Порт можно переопределить через `--port`.

## Проверка

```sh
python3 -m lab11.verify
python3 -m unittest discover -s lab11 -v
```

Первая команда отправляет 18 запросов к локальным экземплярам HTTP-сервера, сравнивает результаты с ожиданиями и сверяет полные ответы с [зафиксированным JSON](results/api_examples.json). Вторая проверяет транспорт, совместную работу модели и фильтра допуска, а также выдачу изображений. [Матрица случаев](cases.md) показывает ожидаемое и фактическое поведение.

Настройки и отпечатки файлов находятся в [config.json](config.json). Путь к другой конфигурации задаётся через `--config PATH`. Для воспроизведения результатов используйте опубликованную версию настроек. Если параметры эксперимента меняются, сохраните новую версию конфигурации.

## Границы применения

Модель сравнивает слова в описаниях. Английский бриф в контрольном сценарии даёт пустую выдачу, а жанровые замены покрывают только формы из словаря. `score` выражает косинусное сходство, а решение о пригодности и правах по-прежнему требует человека. Значение NDCG@3 0,355740 для кандидата относится к отложенному тесту ЛР 9. Проверки HTTP подтверждают воспроизводимость интерфейса. [Результаты ЛР 9](../lab09/results/test_summary.json)
