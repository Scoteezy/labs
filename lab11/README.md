# Лабораторная работа 11. Минимальный модуль проверки упаковки

Компонент получает оригинальное и обработанное рекламное изображение вместе с областями упаковки. Он проверяет вход, приводит области к 128 × 128 и возвращает структурированную оценку для дизайнера. Штатный метод — 1 − SSIM с порогом 0,017705861976. На validation базовый метод получил F1 0,872727, вариант с локальным квантилем — 0,738462. [Зафиксированное решение ЛР 9](../lab09/results/decision.json)

## Запуск

Выполняйте команды из корня репозитория с Python 3.12.

```sh
python -m pip install -r lab04/requirements.txt
python -m lab11.server
```

В другом терминале отправьте сохранённую пару с изменением текста. Ожидаемый ответ — HTTP 200 и `assessment=suspected_distortion`.

```sh
python -m lab11.verify --request PAIR001_08 | curl -fsS http://127.0.0.1:8765/inspect \
  -H 'Content-Type: application/json' --data-binary @-
```

Сервер остановится по Ctrl+C. `--port` позволяет выбрать другой локальный порт. Экспериментальный режим `--mode candidate` использует отдельный порог.

## Проверка

```sh
python -m lab11.verify
python -m unittest lab11.test_service -v
```

Первая команда выполняет 13 HTTP-сценариев, включая контролируемый сбой кандидата, и сравнивает полные ответы с [api_examples.json](results/api_examples.json). Вторая проверяет функцию, ошибки и запуск сервера в отдельном процессе. [Контракт](contract.md) · [Ожидаемые и фактические ответы](cases.md)

[Конфигурация](config.json) фиксирует ограничения и SHA-256 решения ЛР 9. При старте API читает пороги из этого файла решения. Пересчёт оценки на всём наборе запускается отдельно командой `python -m lab09.experiment check`.

## Границы

Вход — однофреймовые RGB PNG и заданные области одной почти фронтальной упаковки. Дизайнер принимает итоговое решение и при необходимости сравнивает трудные пары вручную. Автоматическое определение областей и работа со сложными ракурсами выходят за пределы пилота. Оценка отражает различие яркостных фрагментов. Качество на реальных генеративных изображениях ещё предстоит измерить.
